# financial-opportunities execution procedure

Semantic authority is `contracts/world/financial-opportunities/`.

This is a downstream investment/opportunity qualifier. It does not own the financial graph and must not reconstruct engineering, industrial, policy, resilience or resource-allocation topology.

Current execution is `contract-only`; the registry task is disabled. Future qualification consumes an admitted resource-allocation candidate plus a financial-signals snapshot, then evaluates point-in-time valuation, explicit scenarios, risk, catalysts/invalidators and reproducible financial evidence.

A strong industrial or policy signal is not an actionable opportunity by implication. Missing graph paths, issuer/instrument mappings, current valuation or material downside evidence remain coverage gaps.
