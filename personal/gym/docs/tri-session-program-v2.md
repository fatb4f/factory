# Gym tri-session adaptation program v2

Status: baselining active program contract.

Supersedes `ankle-knee-pelvis-tri-session-v1` for future sessions. Historical v1 sessions remain attached to v1 and are not reinterpreted against this topology.

Machine-readable authority: `contracts/personal/gym/tri_session_program_v2.cue`.

## Control objective

The lower chain is still producing substantial adaptation/reorganization from relatively small training inputs. Recovery also carries a meaningful cognitive cost that can reduce academic throughput.

The current controller therefore optimizes for:

```text
minimum useful loaded exposure
        +
clear attribution of response
        +
hard recovery protection
        +
no extra training day for upper body
```

The governing invariant is:

> Preserve lower-chain organization and academic/cognitive recovery while adding only the minimum loaded exposure required to build capacity.

## Session topology

```text
A — posterior foundation
GHR
reverse hyper
Copenhagen
+ rear-delt high row

B — anterior foundation
ATG split squat
reverse Nordic
resisted hip flexion
+ overhead press

C — sparse integration
low-cost distal state setting
frog bridge
exactly one:
  Cossack
  OR modified Standing-Bow SLRDL
+ lateral raise
```

Activation and gait readouts remain available, but they are not license to accumulate more working volume.

## Why there is no Program D

A separate upper-body session would create another recovery event. At present, recovery days are hard no-training domains because both physical reorganization and cognitive recovery matter.

Upper-body strength is therefore distributed across A/B/C:

| Program | Upper exposure | Main role |
| --- | --- | --- |
| A | rear-delt high row | posterior delt / upper-back load sharing |
| B | overhead press | global shoulder strength and upward-rotation integration |
| C | lateral raise | direct lateral-delt capacity |

This is one upper working exposure per training event, not a fourth program.

A-Y-W raises, band pulls, and similar low-load control work remain optional state-setting tools. They are not considered a substitute for progressive upper-body strength and are not automatically performed during hard recovery.

## Recovery contract

Recovery is state-driven, not weekday-driven.

Current calibration from the last observed instances:

| Program | Last observed recovery requirement |
| --- | ---: |
| A / posterior | ~72 h |
| B / anterior | ~48 h |
| C / integrated | not yet baselined |

These values are observations, not automatic admission clocks.

The active rule is:

```text
session closes
    ↓
hard no-training recovery domain
    ↓
movement availability recovered
AND local tissue state acceptable
AND systemic energy acceptable
AND cognitive / academic bandwidth acceptable
    ↓
next session admitted
```

Time alone does not admit the next session.

## Exercise-count progression

At present, adding exercises is treated as its own progression dimension.

Do not increase exercise diversity simply because a session is mechanically successful. Expansion is considered only after repeated runs show:

- stable gait and basic movement availability;
- no material new ankle-knee-hip negotiation after the session;
- no new guarding pattern;
- recovery duration is stable or falling;
- cognitive/academic throughput is not materially degraded.

Progression order is therefore generally:

```text
cleaner execution
→ repeatable ROM
→ repeatable reps
→ load / assistance change
→ only later: exercise-count expansion
```

## Program A — posterior foundation

### Required working exposures

1. `ghr`
2. `reverse-hyper`
3. `copenhagen`
4. `rear-delt-high-row` as the only loaded upper-body exposure

The posterior foundation is not currently reducible without changing the purpose of the program.

### GHR

Maintain the existing contract:

```text
ankle neutral
AND femoral position organized
AND hamstring acquired
AND hips / torso stacked
AND pelvis neutral
→ rep admitted
```

Progress only one of ROM, assistance, reps, or external load at a time.

### Reverse hyper

Retain both roles:

- very-light primer when useful;
- controlled secondary posterior-chain work.

Working reps remain hip-driven with a stable pelvis and no lumbar swing.

### Copenhagen

Copenhagen remains required because it supplies frontal-plane pelvic control and direct adductor/trunk force transfer that GHR and reverse hyper do not provide.

### Rear-delt high row

Canonical setup:

```text
seated cable / lat-row station
Y attachment
pronated hands
elbows out
hands drawn toward sternum
```

The movement should load posterior delt / upper-back capacity without forcing maximal scapular retraction.

Initial prescription:

```text
2 × 8–12
~3–4 RIR
```

Progress only if the neck remains quiet, levator contribution does not rise, scapular excursion stays controlled, and humeral position remains clean.

## Program B — anterior foundation

### Required working exposures

1. `atg-split-squat`
2. `reverse-nordic`
3. `resisted-hip-flexion`
4. `overhead-press` as the only loaded upper-body exposure

Poliquin step-up remains a primer/measurement surface rather than another hard quad lift.

### ATG split squat

The split squat remains foundational because one task simultaneously exposes:

- front-leg knee flexion and dorsiflexion;
- quad output;
- rear-hip extension tolerance;
- bilateral pelvic force transfer.

Progress clean ROM and reduced assistance before load.

### Reverse Nordic

Reverse Nordic remains the bilateral long-length anterior-chain foundation.

Preserve:

- hips extended;
- ribs stacked;
- starting knee relationship;
- controlled eccentric;
- clean deep-flexion-to-concentric reversal.

### Resisted hip flexion

This is now treated as the required anterior core / hip-flexor strength slot rather than layering a second dynamic GHD core exposure on top.

Supported implementations remain:

- bilateral cable hip flexion;
- unilateral cable knee drive;
- secure foot-suspended resistance such as a kettlebell.

Pelvic rotation, lumbar arching, rib flare, or momentum terminate the useful set.

### Overhead press

Initial prescription:

```text
2 × 6–10
~3–4 RIR
```

The target is shoulder strength with free scapular upward rotation, not maximal pressing output.

Do not use a forced “shoulders back and down” strategy.

Stop/regress if:

- neck or levator tension rises;
- sternal/anterior-thorax tension rises;
- internal-rotation bias becomes more obvious;
- humeral centering/control deteriorates.

## Program C — sparse integration

Program C is deliberately reduced relative to v1.

Its job is to test whether A/B adaptations can coexist, not to create a third large lower-body perturbation.

### Entry state

Use only low-cost distal preparation required to make the chain available:

- short backward walk if useful;
- inversion/eversion;
- dorsiflexion;
- neutral calf work.

These are state setters, not conditioning.

### Frog bridge

Use one low-dose soles-together frog bridge exposure to establish glute-adductor cooperation:

```text
soles together
knees near 90°
active outward knee drive
symmetric pelvis
hip extension without lumbar substitution
```

### Exactly one principal integration family

Each Program C run selects one:

#### Cossack

Select when the higher-signal problem is:

- frontal-plane redistribution;
- long-length adductor capacity;
- receiving-foot/knee organization.

#### Modified Standing-Bow SLRDL

Select when the higher-signal problem is:

- unilateral hinge control;
- stance-hip lateral organization;
- femoral/pelvic control;
- contralateral whole-body integration.

Do not perform both as working lifts in the same current-baseline C session.

### Lateral raise

Initial prescription:

```text
2 × 10–15
~3–4 RIR
```

Use a comfortable scapular-plane path. The neck should remain relatively quiet and shrugging should not become the dominant strategy.

## Shoulder-girdle hypothesis boundary

Current upper-body programming is based on a working capacity hypothesis:

```text
anterior pressing demand
        +
possibly underexposed posterior/lateral shoulder capacity
        ↓
poor load sharing may become visible as
neck / levator / anterior-thorax tension
or an internal-rotation bias
```

This is not encoded as a diagnosis.

The relevant controller signal is whether progressive posterior/lateral shoulder strength improves load sharing while preserving:

- quiet cervical musculature;
- controlled humeral position;
- free scapular motion;
- comfortable thoracic mechanics.

A movement that increases the current neck/sternal tension is not admitted merely because the target muscle can complete the reps.

## Progress model

Progress remains multidimensional:

- cleaner ROM at unchanged assistance/load;
- lower assistance at unchanged mechanics;
- more repeatable reps;
- reduced side-to-side concentration of effort;
- less post-session chain reorganization;
- stable or shorter recovery;
- lower cognitive cost;
- cleaner gait after the session.

The target remains a Pareto improvement in usable capacity, mechanical quality, redistribution, and recovery cost rather than a conventional strength PR.
