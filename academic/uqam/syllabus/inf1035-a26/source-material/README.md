# INF1035 A26 source-material projections

This directory vendors readable UTF-8 projections of the source material supplied for INF1035.

| Projection | Original source | Semantics |
|---|---|---|
| `calendar-a26.md` | `Calendrier_INF1035_Automne_2026.pdf` | faithful text/table projection |
| `chapter-01-introduction.md` | `INF1035 - Chapitre 01 - Introduction.pdf` | structured text projection; figures/layout omitted |

The original PDF bytes are not reproduced here because the File Library interface available to this run exposes parsed content rather than transferable raw bytes. The original filenames remain the source identities used by `sources.cue` and `materials.cue`.

These projections exist for Git-native reading, search and downstream normalization. They do not replace the source PDFs when page layout, figures or exact byte identity matters.
