# Lazymux

Lazymux presents a menu for installing other tools in Termux. Its relevance here is identifying the menu-driven project often described as a Termux security framework.

## What you need

Termux and the dependencies of the individual tool. A listing alone does not establish current package or Android compatibility.

## Measurement workflow

Use the menu as a catalogue. Open a candidate's upstream documentation, determine whether it accepts saved captures or requires hardware, and evaluate it on a known recording. Record the actual analysis tool and version in the result.

## Limits and interpretation

Installation is the capability provided by Lazymux. Measurement quality, supported radios, capture privileges and data formats belong to each selected program. For the survey workflows here, direct upstream packages are sufficient.
