# Lucy courier observation and communications

These design notes propose an optional observation capability for a consenting courier and recipient during a staged outdoor handoff near Montréal. The current MVP uses physical custody, recipient authentication, and an authenticated receipt. UAVs are outside its scope. Visibility of an exchange can aid incident response. It carries no authority to close a shipment.

The proposed order is a single-aircraft trial, then a two-aircraft staged relay. The wearable incident capture can be evaluated independently. No equipment purchase, field deployment, or site authorization is implied.
