# Canadian initiatives

This directory documents Canadian and Quebec initiative authorities that create, redirect, finance, or constrain engineering and industrial demand.

These are not aliases for the engineering, industrial, or financial graphs. They are independent policy/project-demand authorities whose admitted observations may later be consumed through explicit cross-domain bridges.

## Current acquisition

Canadian initiative watches use bounded manual or agent-assisted acquisition from authoritative public surfaces. Each observation preserves source/channel/record/revision/acquisition provenance and terminates as a typed event or explicit coverage gap.
