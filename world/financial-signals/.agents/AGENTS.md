# financial-signals execution procedure

Semantic authority is `contracts/world/financial-signals/`.

The financial domain owns financial topology only: issuers, reporting segments, instruments, capital structure, financing claims, revenue/earnings relations and time-qualified market/financial measurements. It must not duplicate industrial, engineering, clean-energy or climate-readiness topology.

The current contract supports an `event-watch`, but the Factory registry keeps this task disabled until an initial issuer/hypothesis/source universe is explicitly configured. When enabled, prefer regulatory filings, issuer filings/IR, exchange/reference sources, financing disclosures and reproducible market/benchmark observations. Media and analyst material are discovery/supporting evidence unless separately admitted.

A hypothesized relation is never an admitted `#FinancialRelation`. Price, revenue, backlog, share count, debt, multiples and similar values remain time-qualified measurements.

Write admitted runs under `world/financial-signals/runs/<run-id>/manifest.json` conforming to `#RunManifest`.
