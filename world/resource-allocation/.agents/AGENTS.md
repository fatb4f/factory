# resource-allocation execution procedure

Semantic authority is `contracts/world/resource-allocation/`.

This domain is a coordination/control surface over independently admitted graph snapshots. It owns no engineering, industrial, clean-energy, climate-readiness or financial source facts.

Current execution is `contract-only`; the registry task is disabled.

When correlation is later enabled:

1. consume immutable, domain-qualified snapshot references;
2. validate bridge hypotheses separately from admitted bridges;
3. establish shared-resource identity only from qualified cross-domain evidence;
4. represent each demand through an explicit source-domain path;
5. require at least two independently admitted demands for a cross-graph conjunction;
6. generate intervention candidates without mutating source-domain topology;
7. consume financial qualification as evidence, never as source-domain truth;
8. keep allocation decisions fail-closed on material identity, demand, bridge or financial coverage gaps.

Do not create a generic Factory graph abstraction from this package until multiple domains demonstrate a genuine invariant.
