## Page projection

1. **Introduction** — INF1120 Programmation I; Mélanie Lord; UQAM.
2. **Programmes** — a program is a sequence of written instructions used to accomplish a specific task on a computer. The diagram models **inputs → program → outputs**.
3. **Examples** — input / processing / output examples: compute age from birth/current dates; derive the permanent code prefix from identity fields; test whether a number is between 1 and 5.
4. **Langage machine** — bit-pattern instructions; directly understandable/executable by the processor; machine-dependent; difficult to read/write/modify/debug.
5. **Assembly and high-level languages** — assembly uses mnemonic symbols and remains low-level/machine-dependent; high-level languages include C, C++, Python, Ruby, Java, use more human-readable expressions, reduce program length, and are machine-independent at the source level.
6. **Compilation et exécution** — a compiler translates one language to another. The diagram shows source code → compiler → executable machine code for a compiled language such as C.
7. **Java execution** — diagram: Java `.java` source → Java compiler → Java bytecode `.class` → JVM → processor-executed machine code. The slide labels Java as *semi-interprété*.
8. **BlueJ** — BlueJ is an IDE (*Integrated Development Environment*) for Java development.
9. **Cycle de vie du logiciel** — simplified waterfall: **Spécifications → Conception → Réalisation (codage) → Vérification → Maintenance**, with feedback arrows to prior stages. Outputs are respectively functional requirements, conceptual solution, software solution, tests, and corrections/improvements.
10. **Utility of the lifecycle** — better control of time/cost and production of quality software conforming to requirements.
