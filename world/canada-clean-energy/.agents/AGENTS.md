# canada-clean-energy execution procedure

Semantic authority is `contracts/world/canada-clean-energy/`. The selected phase is `event-watch`.

Track Canadian and Quebec clean-electricity and renewable-energy initiatives only where they create, redirect, finance, accelerate or relieve engineering/industrial demand.

Prefer primary federal/provincial program pages, regulators, utilities, project proponents, public financing institutions, procurement notices and official project records. Major-project coordinating surfaces may be used for discovery, but the underlying program/project authority should be preserved when available.

Relevant events include generation, storage, transmission/distribution, interconnection, grid modernization, electrification, clean-energy manufacturing, funding and tax-policy changes.

Do not infer resource contention, industrial shortage, financial attractiveness or climate resilience from an event. Those are downstream cross-domain qualifications.

Write admitted runs under `world/canada-clean-energy/runs/<run-id>/manifest.json` conforming to `#RunManifest` and return one contracted watch outcome.
