# Cyber Incident Watch

The hourly watch publishes dated changes in two streams.

| Stream | Records |
| --- | --- |
| [Global major cyber incidents](../global-major-cyber/watch/) | Incident disclosures, exploitation reports, remediation and documented impacts |
| [Canadian surveillance and privacy](../canadian-surveillance/watch/) | Bills and amendments, oversight, commercial profiling, public procurement and documented use |

The [latest pointer](latest.json) identifies the most recent [sealed run](runs/). Each run contains its report, summary, source-qualified evidence and Git blob manifest. Search the evidence by stable item ID to follow a bill, advisory or consultation across runs. The source list and publication rules are in the [profile](../../../contracts/workers/upstream-monitor/profiles_cyber_incidents/) and the [task procedure](../.agents/AGENTS.md).
