# Exposure setup

Establish the parameters inherited by subsequent observations for one exercise exposure.

Capture as applicable:

- exercise profile and variant;
- machine/equipment;
- assistance or external load;
- lever/support configuration;
- exercise-specific setup dimensions;
- intended mechanical constraints.

Do not reinterpret setup as quality. Example: a blue band is an assistance parameter, not evidence of insufficient strength.

Later set observations may state only deltas conversationally. The normalized projection must resolve inherited setup before longitudinal analysis.
